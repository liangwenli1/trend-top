# Trend Top 订阅文案与 UI 方案

日期：2026-09-18。保持现有黑白、蓝色强调、方角与清晰分隔线的风格。

## 1. 结论

Pro 应卖“持续跟踪与提醒”，用三项让用户理解付费后的结果：每日开源摘要、关注项目变化、保存筛选提醒。语言、主题、时区是配置项；同产品去重是数据质量；有历史才出现图表是数据边界。这些无需在套餐卖点中逐条展开。

首页、邮件设置中的引导可用 Get started；付款前的最终动作必须说明订阅 Pro 及实际价格、币种、周期，避免把登录或配置误认为免费试用。

以上是官方页面内容与结构调研，并非逐像素视觉审计。下面的颜色、间距和布局是针对 Trend Top 的设计建议。无需照搬竞品的品牌颜色、圆角或多档企业套餐。

## 3. 推荐文案

### 定价页标题

英文：Stay ahead of open source.

副标题：Explore for free. Follow what matters with Pro.

中文：发现开源新动向。副标题：免费探索，用 Pro 持续关注重要变化。

### Free

适合偶尔探索项目的用户。英文：Explore at your own pace.

- 浏览趋势与排行 / Browse trends and rankings
- 探索项目与来源 / Explore projects and sources
- 查看公开数据与对比 / View public data and comparisons

按钮：Explore projects / 探索项目。登录后用 Current plan 状态代替重复升级动作。

### Pro

适合希望持续跟踪项目的用户。英文：Keep up with what matters.

- Daily open-source digest / 每日开源热点摘要
- Watchlist changes / 关注项目变化
- Saved-search alerts / 保存筛选提醒

按钮：Get started / 开始使用。已经是 Pro 时显示 Manage subscription / 管理订阅，避免再次购买。

卡底一行：Renews automatically. Cancel renewal anytime. / 自动续费，可随时取消续订。

价格必须读取当前后台配置；年付显示实际每年扣款总额，可辅以折算月价。只有根据实际月/年价格计算得到正向优惠时才能显示节省比例。配置缺失时显示暂不可购买；不展示虚构价格、限时优惠、免费试用或保证每天有内容。

## 4. 建议 UI

桌面使用 Free 和 Pro 两列卡片，手机上下排列。卡片方角、白底、细边框。Pro 顶部用蓝色细线与黑色 Pro 状态，不增加花哨渐变或无依据的 Most popular 标签。

内容顺序：

1. 一句主标题与副标题。
2. 卡片：套餐名、适用对象、价格与周期、三条权益、一个居中的按钮。
3. 三个短 FAQ：什么时候开始收到邮件？如何取消续订？如何申请退款？
4. 支持邮箱、退款/条款/隐私入口。

月付/年付切换在价格附近。固定按钮区域高度，避免切换周期后版式跳动。黑色功能按钮文字居中；方向箭头独立定位，不能把文字挤向左侧。移动端不依赖横向滚动查看价格或权益。

共同基础功能不做冗长对比表。如果用户确实需要详细说明，用卡片下的说明区域展开，仍保持价格、自动续费、取消方式直接可见。

## 5. 账户信息架构

头像菜单只留 Subscribe & billing、Settings、Sign out。邮箱是身份说明，不算额外入口。

Subscribe & billing：当前套餐、周期与续费日期、取消付费续订、付款记录、退款申请与支持。

Settings：Email preferences、Watchlist、Saved searches；管理员额外显示 Site administration，普通用户没有这个标签或管理内容。服务器继续校验管理员身份，隐藏 UI 不能代替权限校验。

**邮件暂停、恢复、停止放在 Settings → Email preferences。** 它们不改变 Pro 权益，也不取消付费续订。停止邮件需要明确确认；付款续订取消与退款保持独立流程。

旧账户邮件/关注/保存筛选入口转换到 Settings 对应分类，邮件中的管理与停止链接仍有效。不增加 Overview。

## 6. 来源和套餐标签

Official：蓝底白字、认证形状图标。仅表示项目来源有官方证据，不宣称安全认证。

Community：白底蓝字、蓝色边框与社区图标。保留同等可读性，避免暗示社区项目没有价值。

Pro：黑底白字、蓝色侧线；Free：白底蓝字、空心圆。来源身份与付费权益使用不同造型，不能因为购买 Pro 获得 Official 身份。所有标签同时保留文字，不依赖颜色理解。

## 7. 本次已实施与后续边界

已实施：三入口菜单、两类账户页面、管理员设置嵌入、邮件启停放 Settings；首页 Get started 居中；各邮件共用居中品牌图标；移除页脚 Cookies 链接；Skill 弹窗及名称/路径搜索；来源与套餐标签；精简共享 Pro 权益和定价页价值说明。

保留：隐私页对实际登录 Cookie 的说明、明确的金额/续费/退款信息、后台实际权益与配置功能。

后续建议：将现有定价页整体收敛为 Free/Pro 双卡及短 FAQ。本文提出完整结构，但本次没有直接替换整套定价页，也没有更改价格、支付模式或开通新试用政策。

## 8. 验收与观察

构建与相关回归：账户 API、计费、邮箱验证码、摘要、邮件发送、Skill 分类与分组。人工检查普通/管理员视图、旧链接、Skill 弹窗键盘关闭与手机排版、CTA 与邮件品牌居中。

上线后观察定价页到登录/结账转化、实际付费完成、首次配置摘要成功、提醒留存与退款反馈。优先确认用户能说清 Pro 的三项结果，再决定是否需要更多套餐或更详细的对比表。没有实际量化数据前，不用“效率提升百分比”等承诺。
