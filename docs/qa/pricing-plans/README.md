# Free / Pro 双卡定价页验收

日期：2026-09-18。实现提交 d23007d；关闭订阅确认框后的焦点修复提交 5025182。功能代码先提交推送，然后检查 UI。

## 实施内容

- Free / Pro 双卡；黑白、蓝色强调与方角；功能按钮黑色并居中。
- Pro 仅突出每日摘要、关注项目变化、保存筛选提醒三项结果。
- 后台配置决定价格与可购周期；年付直接展示完整年费。
- Free 用户先确认套餐、金额、币种及政策；已有 Pro 显示当前套餐与管理订阅。
- 三个短 FAQ 解释邮件、取消续订和退款；支持邮箱与购买政策直接可见。
- 邮件暂停、恢复和停止留在 Settings；付款续订留在 Subscribe & billing。

## 验证结果

生产构建通过。相关回归 4 项通过：server/billing.test.js（1）、server/pricing-cache.test.js（2）、server/pro-access.test.js（1）。覆盖计费权限、结账与 webhook 幂等、Pro 权益和语言价格缓存。Radix 的 use client 和主包体积提示是既有构建警告。

人工检查使用 localhost:3125 隔离 Demo 数据库及已有合成 Free / Pro 账户；不接真实邮箱或真实支付。测试配置为英文 USD 月付 9.99、年付 79；中文 CNY 月付 68、年付未配置。这些只是 QA 数据，并非修改生产价格。
