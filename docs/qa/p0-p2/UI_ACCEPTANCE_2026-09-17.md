# P0 / P1 / P2 后续修正与本地页面验收

日期：2026-09-17。代码版本：`9eab9f8`。对应竞品报告第 13、14、15 节及 P0 / P1 / P2 交付。代码先提交推送，再打开修改后的页面检查，继续使用黑白蓝与方形控件。

## 1. 这轮修正

| 问题 | 影响与原因 | 最终处理 |
| --- | --- | --- |
| P1：筛选改变 Hot score | 分数的比较组跟着筛选缩小，同一个项目可能从 89 变成 17，用户无法判断是否真的降温 | 六类均固定在同类型、同时间窗口的有效比较组计算，筛选只改变展示集合；接口提供 `scoreScope: type-period` |
| P1：点击 Topic / Language 丢失其他条件 | 标签链接没有完整保留 Use case、Official 等查询条件 | 共用查询构造器，切换榜单 / 图表、点击标签和清除单项条件保留其余筛选 |
| P1：未知日期或计数变成有效数据 | NULL 被转成零或日期零点，可能把未知年龄归为新项目、把缺失值画成真实零 | 保留未知；未知日期不获得新项目资格或近期活动加分；图表明确区分未知与真实零 |
| P1：邮件设置入口跳到 Pricing | 账户菜单复用了主页的 Pro 升级入口 | 菜单直接进入邮件设置；主页升级入口仍保留登录后进入 Pricing 的专用意图 |
| P2：长 Topic 被挤到下一行 | 桌面主题列过窄 | 增加主题列宽，保持指标列间距；小于等于 1100px 使用可读的卡片布局 |
| P2：320px 详情页横向溢出 | body 最小宽度没有扣除滚动条 | 去除固定最小宽度，长标题正常换行 |
| P2：360px Free 升级按钮横向溢出 | 长文案禁止换行 | 按钮宽度不超过容器，允许换行，保留完整文案 |
| P2：组件网格标签与操作挤在一起 | 行内元素、文本边距和操作布局混用 | 分开标题、说明、Topic 和操作；操作区域保留点击高度，Topic 改为可筛选的方框链接 |
| P2：图表 Tooltip 信息不足 | 只显示通用字段名，计数单位和比例不明确 | 语言 Tooltip 展示语言、数量、单位和占比；一个样本显示 `1 item`，不遮挡环图中央数字 |

## 2. 验收环境与边界

使用隔离 localhost Demo、内存 PGlite 和虚构的 Free / Pro 账户。没有连接生产数据库，没有发送真实邮件、启动外部抓取、购买、取消付费续订或退款。

公开榜单与稳定评分在更新后的 API 实例验证。账户、保存筛选和组件交互使用另一个隔离实例，其后台早于稳定评分修正，因此不把该实例的分数用作稳定评分证据。所有页面使用当前构建产物。

检查宽度包括 320、360、390、768、920、1024、1280、1440px；不是每个页面都覆盖全部尺寸。它们是同一桌面浏览器中的视口模拟，不代表真机验收。截图中的黑色图表外框是点击后的焦点指示。
