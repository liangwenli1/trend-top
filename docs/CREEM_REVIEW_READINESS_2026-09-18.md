# Creem 审核整改与账户概览

## 本轮修改

截图中的具体反馈是缺少可见客户支持邮箱。原页脚的邮箱只在图标提示中出现，不够清楚。

- 公开页脚直接展示客户支持邮箱文字和 mailto 链接，不要求登录。
- 价格页、About、条款、隐私页及账户的各子页面增加客户支持区域，说明三工作日答复时间。
- 默认采用现有品牌发件地址 `support@tapzm.com`；环境变量 CONTACT_EMAIL 和后台已保存邮箱优先。空配置仍显示默认地址。
- 联系信息统一使用一个设置来源；后台保存客服邮箱后，当前页面上的支持区域和页脚同步更新，不需要刷新。
- 账户首页改为“账户概览”：邮箱验证状态、Free / Pro 标记和常用功能入口。去掉修改密码表单及其登录方式查询请求。
- 保留旧密码认证 API 的兼容性，没有删除旧账户、密码记录或 Google 身份。正常客户界面使用邮箱验证码与 Google 登录。
- 价格页补充付款确认后交付、摘要设置、无更新不发送、续订、停止推送、退款及购买政策链接。
- 条款补充真实产品范围和交付方式；隐私页说明邮件服务商处理邮箱和邮件内容。没有修改退款资格、时限、支付路由或取消逻辑。

## 官方清单与本网站对应

参考 [Creem Account Reviews](https://docs.creem.io/merchant-of-record/account-reviews/account-reviews) 和 [Re-Review Guide](https://docs.creem.io/merchant-of-record/account-reviews/re-review-guide)，2026-09-18 读取。

| 核对项 | 本网站处理 | 上线后还需确认 |
| --- | --- | --- |
| 可访问且能实际使用 | 保持公开榜单、详情与定价页面；登录仅用于个人账户 | 生产域名、采集、验证码邮件、摘要任务均正常；没有审核访问阻挡 |
| 产品和价格清楚 | 说明免费发现功能及 Pro 的个性化摘要、变化与提醒；价格仍读取实际后台配置 | 中英文金额、币种及月/年周期与 Creem 产品一致；不以虚构价格填补空配置 |
| 支持邮箱可见 | 公共页面及账户内均明确显示 | 邮箱能收信；与 Creem Business Details、收据上的邮箱一致 |
| 公开法律页面 | 保留免登录的条款、隐私、取消与退款规则，增加直接入口 | 商户主体资料真实，符合实际运营与适用要求 |
| 用户自行取消续订 | 保留套餐与账单的取消操作、确认弹窗及支付方式/收据入口 | 已配置的生产 Creem 取消和门户流程可正常使用 |
| 真实产品信息 | 文案对应现有功能，未添加客户数、评价或保证增长的承诺 | 生产来源与数据展示真实，商标与产品资料需自行核实 |

按当前实现，Trend Top 提供开源发现和趋势摘要，没有向用户提供 AI 图片/视频生成或第三方商家收款功能。本次没有为通过审核添加这些无关功能。

## 验证与范围

构建通过；账单、邮箱验证码、Pro 权限定向测试共 3 项通过，其中覆盖支持邮箱的环境配置、后台覆盖、空配置回退与公开缓存更新，以及取消续订和退款回归。

页面检查在功能代码提交推送后进行，使用隔离本地 Demo 数据。生产商户审核结果、邮件投递、真实支付与客服邮箱收信不属于本地验证结论。

## 推送后本地页面检查

检查使用隔离内存 Demo 数据库，未发送真实邮件、发起支付或修改生产商户资料。

- 1440 × 900 桌面：页脚直接显示支持邮箱；价格页交付、续订、退款与政策链接显示正常。
- 390 × 844 手机：账户入口自动变为单列；邮箱、支持卡片与购买说明没有页面横向溢出。
- 使用已有的、仍保留旧密码记录的测试账户完成邮箱验证码登录，确认账户概览没有密码输入框，账单快捷入口可进入正确页面。
- 退出登录后，从公开页脚进入中文条款和隐私页，确认可以阅读服务、取消、退款与服务商说明。
- 修复法律页标题和段落样式覆盖支持卡片的问题，并再次构建、推送、复查。
- 本轮账户/价格页浏览器记录中没有前端错误。中文价格未配置时如实显示暂未开放；英文金额是本地测试配置，不能据此认定生产定价已配置。

## 你需要完成的商户步骤

1. 部署最新代码，并检查公开页脚、价格页和账户里的邮箱是否是你实际使用的客服邮箱。
2. 在 Creem 的 Settings → Business Details 核对主体、产品网址、业务说明与支持邮箱；同时检查收据上的支持信息。若网站原来配置了其他邮箱，本次继续尊重该配置，需要你自行对齐。
3. 确认价格配置和交付任务均已可用。尚未获批前继续使用 Test Mode，不为审核强行开启生产收款。
4. 修改已上线后，在 Balance → Payout Account 点击 Request re-review。本轮未代你更改商户资料或提交复审，也不保证审核结果。
